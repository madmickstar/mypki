{% extends "base.html" %} {% block title %}Inspect PEM{% endblock %} {# 0.5.0 (page-map §13): the one page that reads a PEM without trying to do anything with it. The posture this template has to hold is unusual for this app: every other page parses a PEM in order to *use* it, and refuses it when it fails a rule. Here nothing is refused, so there is no error surface to render — no amber `.form-errors` block, no status page, no "fix this and submit again". A certificate mypki would never issue still gets a full table, and the findings appear as `.finding` rows under it. That is why this file has no `{% if problems %}`: `app.inspect_submit` catches every parse failure and hands it to `mypki.inspect` as a report, so by the time a template sees anything, it is already a description. What the page must NOT be able to say, and does not: that a chain verifies, that an issuer is trusted, or that a certificate is unrevoked. From 0.7.0 this host publishes a CRL and answers OCSP, but `/inspect` consults neither — it reads the pasted document and nothing else, and it has no trust store. The strongest CA-shaped claim available is therefore still the one inside the document itself, rendered as `BasicConstraints`. #} {% block content %}

  • It does not verify a chain. There is no trust store on this host and no issuer certificate to check against, so it can name an issuer but cannot say that anybody trusts it.
  • It does not know about revocation. This page reads the document you pasted and consults nothing else: not this host's CRL, not /ocsp, not any other CA's. A certificate reported as valid here may still have been revoked by whoever issued it, and a certificate from another CA is not affected by what this host published at all.
  • Its findings are not gates. A SHA-1 signature or an RSA-1024 key is written down rather than refused. The rules that do refuse live on Sign a certificate, which is the page that issues.
  • A private key is named and not opened. Paste one by accident and this page says it is a key, displays none of it, and does not attempt to decrypt it.
