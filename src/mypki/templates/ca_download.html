Install instructions

Windows

  1. Double-click mypki-root-ca.crt → Install Certificate…
  2. Store Location: Local Machine (needs elevation).
  3. Select Place all certificates in the following store → Browse → Trusted Root Certification Authorities.
  4. Finish, then confirm the certificate appears under certlm.msc → Trusted Root Certification Authorities → Certificates.

Command form, from an elevated prompt:

certutil -addstore -f ROOT mypki-root-ca.crt

macOS

  1. Open mypki-root-ca.crt in Keychain Access and add it to the System keychain.
  2. Open the certificate → Show → expand Trust.
  3. Set When using this certificate to Always Trust.

Linux (Debian/Ubuntu and similar)

sudo cp mypki-root-ca.crt /usr/local/share/ca-certificates/mypki-root-ca.crt
sudo update-ca-certificates

update-ca-certificates only processes files ending in .crt, which is why the download carries that extension here too — a file saved as mypki-root-ca.pem would sit in that directory and be silently ignored.

On RPM-based systems, copy to /etc/pki/ca-trust/source/anchors/ and run sudo update-ca-trust extract.

Firefox

Firefox uses its own trust store by default. Either enable Use the system certificate authorities under Settings → Privacy & Security → Certificates, or import the file there and tick This certificate can identify websites.

Java / JDK trust store

keytool -importcert -trustcacerts -alias mypki \
    -file mypki-root-ca.crt \
    -keystore "$JAVA_HOME/lib/security/cacerts"   # default password: changeit

What installation does not do

Installing the root makes issued certificates trusted. It does not make them revocable on its own. From 0.7.0 this host signs a CRL and answers OCSP (/crl), but installing a root copies it into a trust store and stops there: no client is told to consult the CRL, openssl never fetches one even when a certificate carries the pointer, and certificates issued before 0.7.0 carry no pointer at all. A certificate you stop trusting therefore stays valid until it expires unless the client actively asks. Keep validity short.
